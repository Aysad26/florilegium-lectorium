# Флорилегий — Лекторий ПСТГУ

Адаптивная верстка последнего согласованного макета Figma, frame `1834:644` («Правки 02.11 · Desktop»):
https://www.figma.com/design/yUAFW3qmkuFKkOpWpnaMSf/edit?node-id=1834-644

Содержимое готового статического сайта находится в `dist/`. Сторонние библиотеки и сборщик не нужны. Изображения, SVG и шрифты загружаются локально; лицензии шрифтов — в `dist/assets/fonts/`.

## Редактирование

`page-shell.html` содержит шапку, первый экран, темы, авторов и подвал. `sections-content.html` содержит редакционную подборку, рекомендации и выпуски. После изменения этих файлов выполните `node scripts/build.mjs`. Стили находятся в `dist/style.css` и `dist/content.css`.

## Анимация

В первом экране использован исходный согласованный вариант «По эскизу». Механика масок, контуров, удлиненных стеблей и порядок слоев сохранены. Передний белый ободок перекрывает цветы и наушники.

Контроллер `dist/hero-motion.js` ожидает загрузку страницы, шрифтов и четырех изображений анимации, затем запускает раскрытие один раз. Повтор запускается при наведении точным указателем, фокусе с клавиатуры или Enter/Space. Незавершенное воспроизведение не прерывается повторным наведением. При `prefers-reduced-motion` показывается открытое состояние. При ошибке загрузки остается статический исходный знак.

Перед раскрытием показывается небольшой прелоадер с логотипом: минимум 650 мс, исчезновение за 200 мс и пауза 220 мс перед запуском кейса. Если загрузка не завершается, экран снимается автоматически. На мобильных анимация расположена перед заголовком; вводный абзац набран 14 px с интервалом 22 px.

`dist/page-effects.js` и `dist/page-effects.css` отвечают за однократное мягкое появление блоков при прокрутке и увеличение обложек на 3,5% при наведении. Режим уменьшенного движения учитывается; без JavaScript весь контент доступен.

`dist/stats-counter.js` плавно увеличивает цифры статистики от нуля за 1,4 секунды. Счёт запускается один раз, после прелоадера и появления блока на экране. Суффикс «+» сохраняется; при уменьшенном движении, печати или без JavaScript отображаются итоговые значения.

Для локального запуска достаточно статического HTTP-сервера с корнем в `dist/`. Все пути относительные, поэтому сайт можно разместить и в подкаталоге домена.

Оригинальные файлы движка в `dist/motion/` сохранены без изменений относительно демонстрации florilegium-motion-study. Для проверки жизненного цикла: `node --test tests/hero-motion.test.cjs`.

## Навигация

Шапка закреплена сверху при прокрутке. На мобильных экранах до 767 px кнопка личного кабинета всегда видна в шапке, а меню раскрывается кнопкой бургера; Escape, повторное нажатие и нажатие вне шапки закрывают меню. Пункты верхнего меню пока отображаются без переходов — по текущему уточнению. Без JavaScript меню остаётся видимым.

Кейс на мобильных уменьшен ещё на 10% относительно предыдущего варианта (81% ширины, максимум 291,6 px); отступ перед ним и промежуток до текста сокращены ещё на 15%.

## Область реализации

Это верстка главной страницы. Кнопки личного кабинета и регистрации сохранены по макету и отмечены `data-action="account"` / `data-action="register"` для интеграции с системой авторизации. Формы, авторизация и отправка писем не добавлены. Ссылки карточек ведут на соответствующие материалы florilegium.ru. Контакты, политика конфиденциальности и социальные сети в подвале пока отображаются как текст макета: целевые адреса не были заданы.

Существующая демонстрация вариантов анимации сохранена отдельно без изменений.
